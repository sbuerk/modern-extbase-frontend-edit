Partial: Profile/EmailList The email addresses of a profile, including their section heading. Renders nothing when the collection is empty, so a caller never has to ask. Arguments emails iterable of Domain\Model\Email required Pass profile.emails. The iteration order is the manual sorting order, because the ObjectStorage is returned live. f:link.email rather than a hand written mailto href: it honours the spamProtectEmailAddresses configuration of the installation, which a literal href would bypass. The type label is looked up dynamically in the database label file - see Profile/AddressList for why. A hidden record is marked as such - see Profile/AddressList for why, and for why the marker never appears in the read plugins.
