Partial: Profile/AddressList The postal addresses of a profile, including their section heading. Renders nothing when the collection is empty, so a caller never has to ask. Arguments addresses iterable of Domain\Model\Address required Pass profile.addresses. The iteration order is the manual sorting order, because the ObjectStorage is returned live. The type label is looked up dynamically in the database label file rather than repeated here. That file already carries one label per TCA select item, and a template that switched over the known types would silently miss a type added to the TCA later. The raw value is the fallback so that a missing label is visible instead of blank. A hidden record is marked as such. The read plugins never pass one - their collection comes off the parent and is reconstituted with enable fields applied - so the marker is invisible there. The edit plugin does pass them: it reads the collection through the edit repository precisely so the owner sees the records they have hidden, and an unmarked hidden address in that view would read as published.
