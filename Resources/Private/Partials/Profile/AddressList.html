Partial: Profile/AddressList The postal addresses of a profile, including their section heading. Renders nothing when the collection is empty, so a caller never has to ask. Arguments addresses iterable of Domain\Model\Address required Pass profile.addresses. The iteration order is the manual sorting order, because the ObjectStorage is returned live. The type label is looked up dynamically in the database label file rather than repeated here. That file already carries one label per TCA select item, and a template that switched over the known types would silently miss a type added to the TCA later. The raw value is the fallback so that a missing label is visible instead of blank.
