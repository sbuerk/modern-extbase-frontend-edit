=========
Reference
=========

The exact surface of the extension: the tables it adds and every column on
them, what the image upload accepts, the validation rule of every field
together with the label id of its message, and the contract of the JSON
endpoints.

This chapter states what the code does. Why it does it that way is written next
to the code, in the :file:`docs/` directory of the source repository, which is
not part of the rendered manual.
